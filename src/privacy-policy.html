Politique de Confidentialité

Application mobile eMajlis – Conseil Supérieur de l'Éducation, de la Formation et de la Recherche Scientifique (CSEFRS)

1. Introduction

La présente Politique de Confidentialité décrit la manière dont l'application mobile eMajlis, développée par le Conseil Supérieur de l'Éducation, de la Formation et de la Recherche Scientifique (CSEFRS), collecte, utilise, stocke et protège les données personnelles de ses utilisateurs.

En utilisant l'application, vous acceptez les pratiques décrites dans cette politique.

2. Données collectées

L'application collecte les types de données suivants :

  • Données d'authentification : identifiant et mot de passe utilisés pour se connecter à la plateforme HumHub du CSEFRS. Ces données ne sont pas stockées localement de manière permanente — elles servent uniquement à obtenir un jeton d'accès sécurisé.
  • Jeton d'accès : un jeton JWT est stocké de manière sécurisée sur l'appareil (via Expo SecureStore) afin de maintenir la session active.
  • Données de profil : nom, prénom, adresse e-mail professionnelle et photo de profil, tels que définis sur la plateforme CSEFRS.
  • Données de navigation : contenus consultés (actualités, documents, événements) dans le cadre de l'utilisation normale de l'application.
  • Fichiers temporaires : les documents et images téléchargés sont mis en cache temporairement sur l'appareil pour améliorer les performances. Ces fichiers sont automatiquement supprimés par le système.

3. Finalités du traitement

Les données collectées sont utilisées exclusivement pour :

  • Authentifier les membres du CSEFRS et leur donner accès à la plateforme interne eMajlis ;
  • Afficher les contenus, actualités, documents et événements de la plateforme ;
  • Permettre les interactions sociales internes (commentaires, réactions, notifications) ;
  • Assurer le bon fonctionnement et la sécurité de l'application.

4. Partage des données

Les données personnelles des utilisateurs ne sont pas vendues, louées ni partagées avec des tiers à des fins commerciales.

Les données peuvent être transmises aux services suivants dans le cadre du fonctionnement de l'application :

  • HumHub (plateforme interne CSEFRS) : serveur intranet hébergé par le CSEFRS. Toutes les données restent dans l'infrastructure du CSEFRS.
  • Railway.app : hébergement du serveur API backend de l'application. Utilisé uniquement comme intermédiaire sécurisé entre l'application et la plateforme HumHub.
  • Google Docs Viewer : utilisé pour afficher les documents (PDF, DOCX, PPTX) à l'intérieur de l'application. L'URL signée du document est transmise à Google pour rendu. Aucune donnée personnelle n'est transmise.
  • Firebase Cloud Messaging : utilisé pour l'envoi de notifications push. Seul l'identifiant FCM de l'appareil est transmis.

5. Conservation des données

Les données sont conservées aussi longtemps que le compte de l'utilisateur est actif sur la plateforme CSEFRS. Les jetons d'accès expirent automatiquement. Les fichiers en cache sont gérés par le système d'exploitation de l'appareil.

6. Sécurité

L'application utilise les mesures de sécurité suivantes :

  • Communication chiffrée via HTTPS/TLS pour toutes les requêtes réseau ;
  • Stockage sécurisé du jeton d'accès via Expo SecureStore (chiffrement natif de l'appareil) ;
  • Jetons signés (JWT) avec expiration pour l'accès aux ressources ;
  • Aucun stockage de mot de passe en clair sur l'appareil ou le serveur.

7. Droits des utilisateurs

Conformément à la réglementation applicable, vous disposez des droits suivants :

  • Droit d'accès à vos données personnelles ;
  • Droit de rectification des informations inexactes ;
  • Droit à la suppression de votre compte et de vos données ;
  • Droit d'opposition au traitement de vos données.

Pour exercer ces droits, contactez-nous à : contact@csefrs.ma

8. Données des mineurs

L'application eMajlis est destinée exclusivement aux membres et collaborateurs du CSEFRS. Elle n'est pas destinée aux mineurs et ne collecte pas sciemment de données concernant des personnes de moins de 18 ans.

9. Modifications de cette politique

Cette politique peut être mise à jour périodiquement. Toute modification sera notifiée via l'application. La date de dernière mise à jour est indiquée ci-dessous.
